# Lead The Seed

## 概要

**Lead The Seed** は、風の力を操って種を導く独自の操作感が特徴のゲームです。プレイヤーはマウス操作によって風を吹かせ、ステージ内の障害物や地形を乗り越えながら、種を目的地へと導きます。
本作品はUnityインターハイ2019に応募した個人制作ゲームです。

## 特徴

- 風を吹かせて種を動かす新感覚の操作システム
- マウスのみでプレイ可能なシンプルなインターフェース
- ステージごとに異なる地形や障害物を活用したパズル要素
- やさしい世界観と自然の雰囲気を大切にしたデザイン

## 操作方法

- **ワールドマップ画面**
  - マウス左クリック：ステージ選択

- **ステージ画面**
  - マウスドラッグ：風を吹かせる

※本ゲームはすべてマウス操作のみでプレイ可能です。
